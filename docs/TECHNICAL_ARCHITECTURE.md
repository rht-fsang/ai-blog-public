# AI Blog 技术架构文档

## 项目概述

AI Blog 是一个基于 RAG（检索增强生成）架构的智能知识库问答系统，支持上传文档、自动向量化、智能问答。

## 技术栈

### 前端
- **框架**: Next.js 16.1.6 (App Router + Turbopack)
- **UI**: React 18.3 + Tailwind CSS 4
- **AI SDK**: @ai-sdk/react (useChat hook)

### 后端
- **运行时**: Next.js API Routes (Edge Runtime)
- **数据库**: PostgreSQL + pgvector 扩展
- **ORM**: Drizzle ORM

### AI 服务
- **LLM**: 智谱 AI GLM-4-flash
- **Embedding**: 智谱 AI embedding-2 (1536 维)

### 文档处理
- **PDF 解析**: pdf-parse
- **文本分块**: @langchain/textsplitters (RecursiveCharacterTextSplitter)

## 数据流程

### 1. 文档上传流程

```
用户上传文件 (PDF/TXT/MD)
       │
       ▼
   文件解析
       │
       ▼
   文本分块 (RecursiveCharacterTextSplitter)
   - chunkSize: 500
   - chunkOverlap: 100
       │
       ▼
   向量生成 (智谱 embedding-2)
       │
       ▼
   存储到 PostgreSQL (chunks 表)
   - content: 文本内容
   - embedding: 1536维向量
```

### 2. RAG 问答流程

```
用户提问
       │
       ▼
   生成问题向量 (embedding-2)
       │
       ▼
   向量相似度检索
   - 使用 pgvector 的 <=> 操作符
   - 余弦距离计算
   - 阈值过滤 (> 0.5)
       │
       ▼
   构建增强提示词
   system: "你是一个 AI 助手。请根据以下参考资料回答..."
   context: [检索到的相关文档片段]
       │
       ▼
   调用智谱 GLM-4-flash
   - 流式响应
   - max_tokens: 65536
       │
       ▼
   返回给用户
```

```bash

```

```sql
CREATE EXTENSION IF NOT EXISTS vector;
```

### 运行数据库迁移

```bash
pnpm drizzle-kit push
```

## API 接口

### POST /api/chat

聊天接口，支持 RAG 检索增强。

**请求体**:
```json
{
  "messages": [
    { "role": "user", "content": "问题内容" }
  ]
}
```

**响应**: Server-Sent Events (SSE) 流式响应

### POST /api/upload

上传文档接口。

**请求**: multipart/form-data
- file: 文件 (PDF/TXT/MD)

**响应**:
```json
{
  "success": true,
  "documentId": 1
}
```
